# 주간 검토 지침 (매주 Claude가 이 순서대로 실행)

채널 주인은 직접 관리하지 않고 이 검토에 맡긴다. 숫자에 근거해서만 바꾸고, 바꾼 이유를 리포트에 남긴다.

## 1. 데이터 읽기
- `data/state.json` — 올린 영상 목록(날짜, 구절, 주제, 배경색)
- `data/stats/videos.json` — 영상별 조회수·좋아요·댓글, `last28d`(시청 지속률 `averageViewPercentage`, 구독 전환 `subscribersGained`)
- `data/stats/channel_daily.jsonl` — 날짜별 구독자 수
- `data/comments/inbox.jsonl` — 답글을 기다리는 댓글

## 2. 판단 기준
- 1순위 **시청 지속률**(쇼츠 노출을 가장 크게 좌우), 2순위 **구독 전환**, 3순위 조회수
- 영상이 3편 미만이거나 업로드 후 3일이 안 된 영상은 판단에서 뺀다(분석 지연)
- 주제별·배경색별·요일별 평균을 비교한다. 차이가 작으면(±10% 이내) 바꾸지 않는다

## 3. 조정할 수 있는 것
- `data/verses.json` 에서 **아직 안 올린 구절의 순서** (성과 좋은 주제를 앞당기되, 같은 주제가 이틀 연속 오지 않게)
- `config.json` 의 `youtube.title_template`, `hashtags`, `tags` (2주 이상 데이터가 쌓인 뒤, 한 번에 하나만)
- 구절 본문은 절대 고치지 않는다(개역한글 원문 그대로)
- 업로드 시간 변경이 필요하면 리포트에 제안만 쓴다(워크플로 파일은 건드리지 않음)

## 4. 댓글 답글 쓰기
`data/comments/inbox.jsonl` 의 각 댓글에 답글을 써서 `data/comments/replies.json` 에 추가한다
(`[{"thread_id": "...", "text": "..."}]`). 다음 날 아침 자동으로 올라간다. 다 쓴 뒤 inbox 파일은 비운다.

- 따뜻하고 짧게(200자 이내), 존댓말, 댓글 내용을 구체적으로 받아서 답한다(복붙 느낌 금지)
- 기도제목에는 "함께 기도하겠습니다" + 관련된 짧은 말씀 한 구절(개역한글, 출처 표기)
- 질문에는 아는 만큼만 답하고, 교단마다 해석이 갈리는 문제는 "다니시는 교회 목사님과 나눠 보시길" 권한다
- 의료·법률·돈 문제에 대한 조언, 약속, 앱 홍보 문구는 넣지 않는다
- 공격적·비방 댓글, 정치 논쟁은 답하지 않고 건너뛴다(inbox 에서만 지움)

## 5. 리포트 남기기
`reports/YYYY-Www.md` (예: `reports/2026-W48.md`)에 한국어로, 채널 주인이 1분 안에 읽을 수 있게:

```
# 2026년 48주차 리포트
- 구독자: 120명 (+15) / 이번 주 조회수: 3,400
- 가장 반응 좋았던 영상: … (시청 지속률 92%)
- 이번 주에 바꾼 것: …(이유)
- 다음 주 계획: …
- 답글 단 댓글: 12개 / 숨긴 스팸: 3개
- 주인이 확인할 일: 없음  ← 있을 때만 구체적으로
```

## 6. 저장
변경한 파일을 커밋하고 `main` 에 푸시한다. 커밋 메시지: `주간 검토: YYYY-Www`
